# Brasa Marina — Menú digital interactivo

Proyecto académico de menú digital desarrollado con HTML, CSS y JavaScript.

## Archivos
- `index.html`: estructura del sitio.
- `styles.css`: diseño adaptable a celulares y computadoras.
- `script.js`: productos, filtros, carrito y pedido por WhatsApp.

## Configurar WhatsApp
Abre `script.js` y reemplaza `593999999999` por el número real del restaurante, en formato internacional y solo números. Para Ecuador, utiliza `593` seguido del número celular sin el cero inicial.

## Publicar en GitHub Pages
1. Inicia sesión en GitHub y crea un repositorio público llamado `brasa-marina`.
2. Sube los tres archivos (`index.html`, `styles.css` y `script.js`) a la raíz del repositorio. También puedes subir `README.md`.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. Espera unos minutos. GitHub mostrará el enlace público del menú en la misma sección Pages.
